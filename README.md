# 💍 Indian Weddings Cost Analysis

## 📌 Project Overview

This project performs an **Exploratory Data Analysis (EDA)** on an Indian Weddings dataset to understand how different factors influence wedding expenses. The analysis focuses on identifying cost trends across wedding types, locations, decoration categories, entertainment options, gifts, and invitation cards using Python and data visualization techniques.

---

## 🎯 Objectives

* Clean and preprocess the raw dataset.
* Analyze wedding costs across different wedding types.
* Compare average wedding expenses by location.
* Study the impact of decoration, entertainment, gifts, and invitation categories on overall costs.
* Visualize insights using informative charts and graphs.

---

## 📊 Dataset

The dataset contains information related to Indian weddings, including:

* Wedding Type
* Wedding Cost
* Wedding Location
* Decoration Cost & Category
* Entertainment Cost & Category
* Bride & Groom Clothing Expenses
* Gifts & Gift Categories
* Invitation Card Categories
